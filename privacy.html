Política de privacidad de Alice OpenClaw

Última actualización: 23 de septiembre de 2026.

Finalidad

Alice OpenClaw es una herramienta personal y privada. Utiliza las API de Google únicamente para ejecutar las solicitudes de su propietario sobre su correo de Gmail y su calendario.

Datos utilizados

La aplicación puede consultar y gestionar mensajes de Gmail, calendarios y eventos, exclusivamente cuando resulte necesario para completar una acción solicitada por el propietario.

Almacenamiento y uso compartido

Las credenciales OAuth se guardan de forma local y privada en el dispositivo del propietario. La aplicación no vende datos, no muestra publicidad y no comparte datos de Google con terceros. Los archivos creados por petición expresa se conservan localmente hasta que el propietario los elimina.

Conservación y revocación

El propietario puede revocar el acceso desde la configuración de seguridad de su cuenta de Google y puede solicitar la eliminación de los tokens y archivos locales en cualquier momento.

Uso limitado de Google

El uso y la transferencia de información recibida de las API de Google cumplen la Política de datos de usuario de los servicios API de Google, incluidos sus requisitos de Uso limitado.
